
# Wedding Invitation App - Curtain / Parda Edition

## Features

- Full-screen curtain / parda opening
- Tap-to-open animation
- Music starts after tap
- Bismillah
- 10 wedding color themes
- Couple photo
- Main wedding details
- Up to 3 additional events
- Google Maps
- Countdown
- Photo gallery
- RSVP
- Wedding wishes
- WhatsApp sharing
- Admin dashboard

## Run on Windows

Open PowerShell in this folder:

python -m venv .venv

.\.venv\Scripts\Activate.ps1

pip install -r requirements.txt

python app.py

Open:

http://127.0.0.1:5000/create

## Example invitation link

http://127.0.0.1:5000/invite/imam-muskan

## Admin

http://127.0.0.1:5000/admin/imam-muskan?key=1234
